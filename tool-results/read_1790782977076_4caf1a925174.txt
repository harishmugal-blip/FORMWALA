   103→   532→   532→**Anti-tear (mandatory — but with height limit):**
   104→   533→   533→```python
   105→   534→   534→from reportlab.platypus import KeepTogether
   106→   535→   535→from reportlab.lib.pagesizes import A4
   107→   536→   536→from reportlab.lib.units import inch
   108→   537→   537→
   109→   538→   538→# Maximum height for KeepTogether blocks: 40% of page height
   110→   539→   539→# Blocks taller than this should NOT be kept together — they cause
   111→   540→   540→# the preceding page to be mostly empty when the block gets pushed down.
   112→   541→   541→MAX_KEEP_HEIGHT = A4[1] * 0.4  # ~336pt ≈ 12cm
   113→   542→   542→
   114→   543→   543→def safe_keep_together(elements):
   115→   544→   544→    """Wrap elements in KeepTogether only if their total height is reasonable.
   116→   545→   545→    If too tall, keep only the FIRST TWO elements together (e.g. title + table/image header)
   117→   546→   546→    to prevent title-content separation, while letting the rest paginate naturally.
   118→   547→   547→    """
   119→   548→   548→    total_h = 0
   120→   549→   549→    for el in elements:
   121→   550→   550→        w, h = el.wrap(A4[0] - 2*inch, A4[1])
   122→   551→   551→        total_h += h
   123→   552→   552→    if total_h <= MAX_KEEP_HEIGHT:
   124→   553→   553→        return [KeepTogether(elements)]
   125→   554→   554→    elif len(elements) >= 2:
   126→   555→   555→        # Keep at least title + first element together to prevent title orphaning
   127→   556→   556→        return [KeepTogether(elements[:2])] + list(elements[2:])
   128→   557→   557→    else:
   129→   558→   558→        return list(elements)
   130→   559→   559→
   131→   560→   560→# Heading stays with first paragraph
   132→   561→   561→story.extend(safe_keep_together([
   133→   562→   562→    heading_paragraph,
   134→   563→   563→    first_body_paragraph,
   135→   564→   564→]))
   136→   565→   565→
   137→   566→   566→# Image + caption: keep together ONLY if image is small
   138→   567→   567→story.extend(safe_keep_together([image, caption_paragraph]))
   139→   568→   568→
   140→   569→   569→# Table title + table: keep together ONLY if table is short
   141→   570→   570→if len(table_data) <= 15:
   142→   571→   571→    story.extend(safe_keep_together([table_title, table]))
   143→   572→   572→else:
   144→   573→   573→    # Long table: just keep title with the table start
   145→   574→   574→    story.extend(safe_keep_together([table_title]))
   146→   575→   575→    story.append(table)
   147→   576→   576→```
   148→   577→   577→
   149→   578→   578→**⚠️ KEY INSIGHT:** `KeepTogether` is the #1 cause of “empty page with chart on next page”.
   150→   579→   579→When a `KeepTogether` block is taller than the remaining space on the current page,
   151→   580→   580→ReportLab pushes the **entire block** to the next page, leaving the current page mostly empty.
   152→   581→   581→**Always use `safe_keep_together()` to cap the maximum block height.**

   258→   687→   687→**Insertion script (single output PDF):**
   259→   688→   688→```python
   260→   689→   689→from pypdf import PdfReader, PdfWriter
   261→   690→   690→
   262→   691→   691→A4_W, A4_H = 595.28, 841.89  # A4 in points
   263→   692→   692→
   264→   693→   693→def normalize_page_to_a4(page):
   265→   694→   694→    """Scale a page to A4 if its dimensions don't match."""
   266→   695→   695→    box = page.mediabox
   267→   696→   696→    w, h = float(box.width), float(box.height)
   268→   697→   697→    if abs(w - A4_W) > 2 or abs(h - A4_H) > 2:
   269→   698→   698→        page.scale_to(A4_W, A4_H)
   270→   699→   699→    return page
   271→   700→   700→
   272→   701→   701→def insert_cover(cover_pdf, body_pdf, output_pdf):
   273→   702→   702→    """Insert cover as first page of body PDF → single output file."""
   274→   703→   703→    writer = PdfWriter()
   275→   704→   704→    # Cover as page 1
   276→   705→   705→    cover_page = PdfReader(cover_pdf).pages[0]
   277→   706→   706→    writer.add_page(normalize_page_to_a4(cover_page))
   278→   707→   707→    # Body pages follow
   279→   708→   708→    for page in PdfReader(body_pdf).pages:
   280→   709→   709→        writer.add_page(normalize_page_to_a4(page))
   281→   710→   710→    writer.add_metadata({'/Title': 'Report Title', '/Author': 'Z.ai', '/Creator': 'Z.ai'})
   282→   711→   711→    with open(output_pdf, 'wb') as f:
   283→   712→   712→        writer.write(f)
   284→   713→   713→```

   365→   794→   794→
   366→   795→   795→```python
   367→   796→   796→# ReportLab: ALWAYS set hAlign='CENTER'
   368→   797→   797→table = Table(data, colWidths=col_widths, hAlign='CENTER')

   395→   824→   824→### Table Cell Content Rule (MANDATORY - NON-NEGOTIABLE)
   396→   825→   825→
   397→   826→   826→**ALL text content in table cells MUST be wrapped in `Paragraph()`. NO EXCEPTIONS.**
   398→   827→   827→
   399→   828→   828→❌ **PROHIBITED** - Plain strings:
   400→   829→   829→```python
   401→   830→   830→data = [
   402→   831→   831→    ['<b>Header</b>', 'Value'],           # Bold won't render!
   403→   832→   832→    ['Pressure', '1.01 × 10<super>5</super>'],  # Superscript won't work!
   404→   833→   833→]
   405→   834→   834→```
   406→   835→   835→
   407→   836→   836→✅ **REQUIRED** - All text in Paragraph:
   408→   837→   837→```python
   409→   838→   838→data = [
   410→   839→   839→    [Paragraph('<b>Header</b>', header_style), Paragraph('Value', header_style)],
   411→   840→   840→    [Paragraph('Pressure', cell_style), Paragraph('1.01 × 10<super>5</super>', cell_style)],
   412→   841→   841→]
   413→   842→   842→```
   414→   843→   843→
   415→   844→   844→**The ONLY exception**: `Image()` objects can be placed directly in table cells.
   416→   845→   845→
   417→   846→   846→### Units with Exponents (CRITICAL)
   418→   847→   847→- PROHIBITED: `W/m2`, `kg/m3`, `m/s2` (plain text exponents)
   419→   848→   848→- RIGHT: `Paragraph('W/m<super>2</super>', style)`, `Paragraph('kg/m<super>3</super>', style)`
   420→   849→   849→
   421→   850→   850→### Numeric Values in Tables (CRITICAL)
   422→   851→   851→- Large numbers MUST use scientific notation: `Paragraph('-1.246 × 10<super>8</super>', style)` not `-124600000`
   423→   852→   852→- Small decimals MUST use scientific notation: `Paragraph('2.5 × 10<super>-3</super>', style)` not `0.0025`
   424→   853→   853→- Threshold: Use scientific notation when |value| ≥ 10000 or |value| ≤ 0.001

   475→   904→   904→### Table Width Management (⚠️ Prevent Table Overflow)
   476→   905→   905→
   477→   906→   906→**Most common table bug: columns overflow the right page margin because colWidths are hardcoded without checking available space.**
   478→   907→   907→
   479→   908→   908→**Iron Rule: The sum of all colWidths MUST NOT exceed `available_width`.**
   480→   909→   909→
   481→   910→   910→```python
   482→   911→   911→from reportlab.lib.pagesizes import A4
   483→   912→   912→from reportlab.lib.units import inch
   484→   913→   913→
   485→   914→   914→page_width = A4[0]  # 595.28pt
   486→   915→   915→left_margin = 1.0 * inch   # 72pt (adjust to your doc's actual margins)
   487→   916→   916→right_margin = 1.0 * inch  # 72pt
   488→   917→   917→available_width = page_width - left_margin - right_margin  # ≈ 451pt
   489→   918→   918→
   490→   919→   919→# ─── Method 1: Proportional widths (RECOMMENDED) ───
   491→   920→   920→# Define column ratios, auto-scale to fit available_width
   492→   921→   921→col_ratios = [0.25, 0.40, 0.20, 0.15]  # must sum to 1.0
   493→   922→   922→col_widths = [r * available_width for r in col_ratios]
   494→   923→   923→table = Table(data, colWidths=col_widths)
   495→   924→   924→
   496→   925→   925→# ─── Method 2: Fixed + flex columns ───
   497→   926→   926→# Some columns have fixed width (numbers, dates), rest fills remaining space
   498→   927→   927→fixed_cols = {0: 80, 3: 60}  # col 0 = 80pt, col 3 = 60pt
   499→   928→   928→fixed_total = sum(fixed_cols.values())
   500→   929→   929→flex_count = 4 - len(fixed_cols)  # total columns minus fixed
