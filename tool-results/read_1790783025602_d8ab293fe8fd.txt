    90→   129→   129→    summary_text = f"This report was generated by {org_name or 'the system'}, containing comprehensive data analysis and insights."
    91→   130→   130→    # Or in English:
    92→   131→   131→    # summary_text = f"This report presents comprehensive analysis and key insights prepared by {org_name or 'the organization'}."
    93→   132→   132→```

    97→   136→   136→- Lines: 2-4 lines (auto-wrap at width boundary)
    98→   137→   137→- Never truncate summary - if too long, reduce to 4 lines max with `...`

   109→   148→   148→## A0.3 - Z-Index Layer Management
   110→   149→   149→
   111→   150→   150→All cover elements must be rendered in strict layer order. No exceptions.
   112→   151→   151→
   113→   152→   152→| Layer | Z-Index | Contents | Rules |
   114→   153→   153→|-------|---------|----------|-------|
   115→   154→   154→| **Layer 0** (base) | 0 | Background fill (white / light gray) | Always rendered first; full page |
   116→   155→   155→| **Layer 1** (background) | 1 | Grids, watermark letters, decorative blocks, large clipped graphics | **MUST enable clip-path** - background elements may extend beyond logical bounds but must be clipped to page physical bounds. Never let background elements inflate PDF page size. |
   117→   156→   156→| **Layer 2** (structure) | 2 | Ultra-thin divider lines, sidebars, corner crop marks | Structural guides that define spatial zones |
   118→   157→   157→| **Layer 3** (content) | 3 | All readable text content | Rendered last, always on top |
   119→   158→   158→
   120→   159→   159→### Clip-Path Enforcement
   121→   160→   160→
   122→   161→   161→```css
   123→   162→   162→/* clip background overflow — ONLY on Layer 1 */
   124→   163→   163→.cover-bg-layer {
   125→   164→   164→  position: absolute;
   126→   165→   165→  inset: 0;
   127→   166→   166→  overflow: hidden;  /* MANDATORY */
   128→   167→   167→  z-index: 1;
   129→   168→   168→}
   130→   169→   169→```
   131→   170→   170→
   132→   171→   171→> ⚠️ **Clip scope = Layer 1 ONLY.** `overflow: hidden` must ONLY be on the Layer 1 background container. Layer 2 (lines) and Layer 3 (text) containers must NOT have `overflow: hidden`.
   133→   172→   172→
   134→   173→   173→###  Anti-Clip Bug (Layer 3 Text Truncation Fix)
   135→   174→   174→
   136→   175→   175→**Symptom:** Cover text is visible but truncated by an invisible boundary.
   137→   176→   176→
   138→   177→   177→**Root cause:** `overflow: hidden` scope too broad, clipping text in Layer 3.
   139→   178→   178→
   140→   179→   179→**Iron rule:**
   141→   180→   180→```html
   142→   181→   181→<!-- ✅ CORRECT - overflow:hidden only on Layer 1 -->
   143→   182→   182→<div class="cover-layer-1" style="position:absolute; inset:0; overflow:hidden; z-index:1;">
   144→   183→   183→  <!-- Background decorative elements -->
   145→   184→   184→</div>
   146→   185→   185→<div class="cover-layer-2" style="position:absolute; inset:0; z-index:2;">
   147→   186→   186→  <!-- Structure lines, no overflow:hidden -->
   148→   187→   187→</div>
   149→   188→   188→<div class="cover-layer-3" style="position:absolute; inset:0; z-index:3;">
   150→   189→   189→  <!-- Text content, no overflow:hidden -->
   151→   190→   190→</div>
   152→   191→   191→
   153→   192→   192→<!-- ❌ WRONG - global overflow:hidden clips text -->
   154→   193→   193→<div class="cover-container" style="overflow:hidden;">
   155→   194→   194→  <div class="layer-1">...</div>
   156→   195→   195→  <div class="layer-2">...</div>
   157→   196→   196→  <div class="layer-3">...</div>  <!-- Text gets clipped! -->
   158→   197→   197→</div>
   159→   198→   198→```
   160→   199→   199→
   161→   200→   200→###  No Page Border/Frame
   162→   201→   201→
   163→   202→   202→**Symptom:** A rectangular border appears around the entire cover page.
   164→   203→   203→
   165→   204→   204→**Iron rule:**
   166→   205→   205→```css
   167→   206→   206→.cover-page {
   168→   207→   207→  border: none !important;
   169→   208→   208→  outline: none !important;
   170→   209→   209→  box-shadow: none !important;
   171→   210→   210→}
   172→   211→   211→```
   173→   212→   212→
   174→   213→   213→###  Minimum Spacing Between Decorative Lines and Text (Line-to-Text Spacing)
   175→   214→   214→
   176→   215→   215→**Symptom:** Decorative lines on the cover (Layer 2 dividers, corner marks, sidebar edges) are flush against or overlapping with text.
   177→   216→   216→
   178→   217→   217→**Iron rule:**
   179→   218→   218→```
   180→   219→   219→Minimum spacing between decorative lines and any text content = U (= W * 0.05)
   181→   220→   220→i.e., at least 1 U of whitespace between line edges and text edges
   182→   221→   221→```
   183→   222→   222→
   184→   223→   223→| Line Type | Minimum Spacing | Notes |
   185→   224→   224→|---------|---------|------|
   186→   225→   225→| Horizontal divider | `U` above and below the line | Line must not be flush against title or body text |
   187→   226→   226→| Vertical sidebar edge | `U` to the right of the line | Text inside sidebar must maintain spacing from the edge |
   188→   227→   227→| Ultra-thick anchor line (Template 01) | `2 * U` to the right of the line | Thick line and title need ample breathing room |

   262→   301→   301→## S3.0 - Cover Overlap Validation (MANDATORY)
   263→   302→   302→
   264→   303→   303→**After generating the cover HTML and before rendering to PDF, run:**
   265→   304→   304→
   266→   305→   305→```bash
   267→   306→   306→node "$PDF_SKILL_DIR/scripts/cover_validate.js" cover.html
   268→   307→   307→```
   269→   308→   308→
   270→   309→   309→This detects text-vs-decorative-line overlaps by rendering the HTML and measuring actual bounding boxes. Exit code 1 = overlap found, must fix before generating the PDF.
   271→   310→   310→
   272→   311→   311→The minimum gap between any text element and any decorative line is **1U (= 5% of page width ≈ 40px on A4)**. This catches the exact bug shown in the "text overlapping decorative lines" screenshots.
   273→   312→   312→
   274→   313→   313→**If the check fails:**
   275→   314→   314→1. Adjust the decorative line's Y position to maintain ≥ 1U gap from the nearest text
   276→   315→   315→2. Or adjust the text block's position/size to avoid the overlap
   277→   316→   316→3. Re-run `cover_validate.js` until it passes (exit code 0)
   278→   317→   317→
   279→   318→   318→---
   280→   319→   319→
   281→   320→   320→## S3.1 - Hero Title Overflow Protection (Title Line-Wrapping)
   282→   321→   321→
   283→   322→   322→**Rule:** Hero title must NEVER exceed its template's width boundary.
   284→   323→   323→
   285→   324→   324→1. If rendered width > max_width → word-wrap (CJK: any character; Latin: space/hyphen)
   286→   325→   325→2. Multi-line hero titles: **lock line-height to 1.15**
   287→   326→   326→3. Maximum lines: **3** — if 4+ lines needed, reduce font size by 4pt increments
   288→   327→   327→4. Minimum font size floor: **32pt** (below this, truncate with `...`)
   289→   328→   328→
   290→   329→   329→### Title Size vs Lines Quick-Reference (Template 01, zone B→C ≈ 225px)
   291→   330→   330→
   292→   331→   331→| Lines | With subtitle | Without subtitle |
   293→   332→   332→|-------|--------------|------------------|
   294→   333→   333→| 1 | ≤ 80pt | ≤ 80pt |
   295→   334→   334→| 2 | ≤ 55pt | ≤ 70pt |
   296→   335→   335→| 3 | ≤ 42pt | ≤ 48pt |
   297→   336→   336→
   298→   337→   337→**⚠️ CJK 3-line titles must reduce to ~42pt.** Do NOT use 50-80pt for 3-line CJK titles — it WILL overlap the Summary zone.
   299→   338→   338→
   300→   339→   339→---
   301→   340→   340→
   302→   341→   341→## S3.2 - Zone Collision Detection
   303→   342→   342→
   304→   343→   343→After placing each text block, check if its bottom edge penetrates the next zone's top:
   305→   344→   344→
   306→   345→   345→1. **Reposition first:** Push the collided zone down by `overlap + 20px` gap. All downstream zones shift together.
   307→   346→   346→2. **Font reduction (if reposition insufficient):** Decrease title by 2pt increments. Floor: **32pt** for titles, 14pt for meta/summary.
   308→   347→   347→3. **Truncation (last resort):** If font reduction hits floor and still collides, truncate with `...`
   309→   348→   348→
   310→   349→   349→---

   312→   351→   351→## S3.3 - Uppercase Lock
   313→   352→   352→
   314→   353→   353→**Force-uppercase when content is English/Latin:**
   315→   354→   354→- Kicker (category label / lead-in text)
   316→   355→   355→- Footer (closing date / document number)
   317→   356→   356→- Background watermark text
   318→   357→   357→- Any Layer 1 decorative text
   319→   358→   358→
   320→   359→   359→CJK text is exempt. Mixed CJK+Latin strings: uppercase only the Latin portions. Use `text-transform: uppercase` in CSS or `.upper()` in code.

   339→   378→   378→

   341→   380→   380→

   354→   393→   393→
   355→   394→   394→## S3.7 - Line-Length Alignment (Line Must Match Text Span)
   356→   395→   395→
   357→   396→   396→**Decorative lines must be sized relative to the text they serve:**
   358→   397→   397→
   359→   398→   398→- **Vertical lines:** height = text block height (± 1U padding above/below first/last element)
   360→   399→   399→- **Horizontal lines:** width ≥ widest text element in its zone (up to 120%, NEVER shorter)
   361→   400→   400→
   362→   401→   401→```css
   363→   402→   402→.vline {
   364→   403→   403→  position: absolute;
   365→   404→   404→  top: var(--content-top);     /* align with first text element */
   366→   405→   405→  bottom: var(--content-bottom); /* align with last text element */
   367→   406→   406→}
   368→   407→   407→.hline {
   369→   408→   408→  width: max(100%, 200px);     /* at least as wide as parent text container */
   370→   409→   409→}
   371→   410→   410→```
   372→   411→   411→
   373→   412→   412→**Checklist:**
   374→   413→   413→- [ ] Every vertical line’s height matches its adjacent text block span
   375→   414→   414→- [ ] Every horizontal line’s width ≥ widest text element in its zone
   376→   415→   415→- [ ] No decorative line is shorter than the text it accompanies
   377→   416→   416→

   380→   419→   419→## S3.8 - Vertical Balance (Anti-Top-Heavy Layout)
   381→   420→   420→
   382→   421→   421→**Problem:** Content clusters at top of page, bottom 40%+ is dead whitespace.
   383→   422→   422→
   384→   423→   423→**Rule:** When total content height < 50% of page height, switch to centered distribution (flexbox `justify-content: center`). Otherwise use anchor grid:
   385→   424→   424→
   386→   425→   425→| Content Volume | Title Anchor | Summary Anchor | Meta Anchor |
   387→   426→   426→|---------------|-------------|----------------|-------------|
   388→   427→   427→| **Sparse** (fill < 50%) | Centered mode | Centered mode | Centered mode |
   389→   428→   428→| **Normal** (fill 50-80%) | `H * 0.30` | `H * 0.48` | `H * 0.70` |
   390→   429→   429→| **Dense** (fill > 80%) | `H * 0.20` | `H * 0.40` | `H * 0.65` |
   391→   430→   430→
   392→   431→   431→**CJK Title Size Compensation:** CJK characters appear smaller at same pt size. Increase by 15-20%:
   393→   432→   432→- CJK Hero Title: 50-80pt (Latin: 45-65pt)
   394→   433→   433→- CJK Kicker: 11-12pt (Latin: 9pt)
   395→   434→   434→- CJK Summary: 17-20pt (Latin: 16-18pt)
   396→   435→   435→
   397→   436→   436→**Checklist:**
   398→   437→   437→- [ ] No cover has >40% dead whitespace at the bottom
   399→   438→   438→- [ ] CJK titles are 15-20% larger than equivalent Latin titles
   400→   439→   439→- [ ] Sparse-content covers use centered distribution
   401→   440→   440→
   402→   441→   441→---
   403→   442→   442→
   404→   443→   443→## S3.9 - Percentage Positioning Requires Known-Size Container
   405→   444→   444→
   406→   445→   445→**Problem:** `top: XX%` resolves against containing block’s height. If height is undefined (all children absolutely positioned), percentages collapse and elements stack.
   407→   446→   446→
   408→   447→   447→**Iron rule:** Container with `top: XX%` children MUST have deterministic height (`height: 100%`, `inset: 0`, or `top` + `bottom` pair).
   409→   448→   448→
   410→   449→   449→```css
   411→   450→   450→/* ✅ Safest: flat structure with px values */
   412→   451→   451→.cover { position: relative; width: 794px; height: 1123px; }
   413→   452→   452→.kicker { position: absolute; top: 225px; left: 95px; }
   414→   453→   453→.title  { position: absolute; top: 292px; left: 95px; }
   415→   454→   454→
   416→   455→   455→/* ✅ OK: wrapper with inset:0 gives it known height */
   417→   456→   456→.content-left { position: absolute; inset: 0; width: 55%; }
   418→   457→   457→.title { position: absolute; top: 26%; }  /* 26% of 1123px ✓ */
   419→   458→   458→
   420→   459→   459→/* ❌ BANNED: wrapper without height, percentage is undefined */
   421→   460→   460→.content-left { position: absolute; left: 12%; top: 0; width: 55%; }
   422→   461→   461→.title { position: absolute; top: 26%; }  /* 26% of WHAT? → overlap */
   423→   462→   462→```
